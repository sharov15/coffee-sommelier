# Кофейный сомелье

Учебное веб-приложение для магазина свежеобжаренного кофе. React, Vite и TypeScript на клиенте, Node.js и Express на сервере. Google Sheets служит базой знаний, а OpenAI Responses API формирует ответы и рекомендации.

## Локальный запуск

Установите Node.js 24 LTS с npm. Выполните из папки проекта в PowerShell:

```powershell
npm ci
Copy-Item .env.example .env
```

Откройте `.env` и заполните `OPENAI_API_KEY`. Затем выполните:

```powershell
npm run dev
```

Интерфейс разработки доступен на [localhost:5173](http://localhost:5173). Vite перенаправляет запросы `/api` на Express. Для проверки той же сборки, которая запускается на Render, остановите режим разработки и выполните:

```powershell
npm run build
npm start
```

Express обслуживает React и API на [localhost:3000](http://localhost:3000). Проверка процесса доступна на [localhost:3000/api/health](http://localhost:3000/api/health).

## Переменные окружения

| Переменная | Значение |
| --- | --- |
| `OPENAI_API_KEY` | Секретный ключ проекта OpenAI с доступом к GPT-6 Luna. Нужен для отправки сообщений. |
| `OPENAI_MODEL` | `gpt-6-luna`, это же значение используется по умолчанию. |
| `SHEET_CSV_URL` | Публичная ссылка на CSV листа. В примере указан действующий экспорт `Лист1` с `gid=0`. |
| `PORT` | Порт Express. Локально по умолчанию `3000`. На Render значение задаёт платформа. |

Если понадобится заменить URL, можно взять CSV-ссылку из меню Google Sheets «Файл → Поделиться → Опубликовать в интернете», выбрав нужный лист и формат CSV. Проверьте, что ссылка открывается без авторизации и содержит заголовки `category,question,answer,tags`.

Сервер кэширует успешную загрузку CSV на пять минут и передаёт в OpenAI до пяти подходящих записей и до восьми предыдущих сообщений. Для русских слов подбор учитывает словоформы, а совпадения с тегами имеют больший вес. Интерфейс хранит текущий диалог в памяти вкладки. Кнопка «Новый диалог» очищает его. `GET /api/health` проверяет доступность процесса и наличие настроек, без вызова OpenAI и Google Sheets.

## Render Free

Для будущего ручного запуска подготовлен `render.yaml`. В Dashboard можно указать те же параметры для Node Web Service с планом Free:

| Поле | Значение |
| --- | --- |
| Build Command | `npm ci --include=dev && npm run build` |
| Start Command | `npm start` |
| Health Check Path | `/api/health` |
| Environment | `OPENAI_API_KEY`, `OPENAI_MODEL`, `SHEET_CSV_URL`, `NODE_VERSION=24.22.1`, `NODE_ENV=production` |

Укажите ключ в настройках сервиса. Express слушает `0.0.0.0` и порт Render. Публичный чат принимает до 12 запросов в минуту с одного IP и обрабатывает до 6 запросов одновременно. Лимиты действуют в памяти одного экземпляра.

## Проверка

`npm run typecheck` проверяет клиент и сервер. `npm run build` также собирает оба компонента. Для проверки с ключом отправьте вопрос о кофе без кислинки, уточните способ приготовления и задайте вопрос о подписке. Проверьте, что карточка меняется вместе с ответом и показывает интервалы 2, 3 и 4 недели. Вопрос о сроках доставки должен отражать только сведения из таблицы.
